# DotStimVisual

## Task
This code runs a random dot motion task using PsychoPy. Participants see moving dots and use the left or right arrow key to indicate the overall direction of motion. The task includes five coherence levels (0.05, 0.1, 0.2, 0.4, and 0.8), which determine the proportion of dots moving in the same direction. Lower coherence levels make it more difficult to identify the direction of motion. The code records participants' responses, accuracy, and reaction times across trials.

## Data Visualization
The code uses Matplotlib to create three graphs to visualize task performance:

Scatterplot: Shows the relationship between coherence level and reaction time, with colors indicating whether each response was correct or incorrect.

Histogram: Shows the distribution of reaction times.

Bar Graph: Compares the total number of correct and incorrect responses.
